# ÉTHER — The Garden Oracle

Art Nouveau-inspired interactive tarot website.

## Architecture
- `public/`: Frontend, manual tarot card selection and animations
- `src/`: Portable AI tarot reading logic
- `netlify/functions/`: Netlify serverless API adapter
- `adapters/cloudflare/`: Future Cloudflare adapter

Never commit `OPENAI_API_KEY`. Configure it as a hosting provider secret.

The original Ethereal Visions Tarot artwork requires appropriate rights before public distribution.
